# Security Policy

## Reporting a Security Issue

If you discover a security vulnerability related to this repository, please report it privately rather than creating a public issue.

Please include:

* A description of the issue
* Steps to reproduce it, if applicable
* The affected file, component, or workflow
* Potential impact
* Any suggested mitigation

## What Should Be Reported

Examples include:

* Malicious code committed to the repository
* Compromised links or downloads
* Exposed credentials or API keys
* Malicious scripts or workflows
* Supply-chain concerns
* Security vulnerabilities in repository automation

## What Does Not Need a Security Report

General model inaccuracies, outdated model information, broken documentation links, or requests for new models can normally be submitted as regular GitHub issues.

## Responsible Disclosure

Please avoid publicly disclosing security-sensitive information until the issue has been reviewed and addressed.

We will make a reasonable effort to investigate reported security issues and take appropriate action.

## Third-Party Models

This repository references many third-party AI models and services.

Security, licensing, privacy, and usage policies for those models are controlled by their respective authors or organizations. Always review the official documentation before deploying a model in a production environment.
