# Contributing

Thank you for contributing to this AI model reference repository.

This project focuses on collecting and organizing useful information about AI models, including open-source/open-weight models, commercial models, APIs, licensing, hardware requirements, and specialized AI systems.

## What You Can Contribute

You can contribute:

* New AI models
* Model updates
* Correct model specifications
* License information
* Official model/source links
* API availability
* Hardware requirements
* Context-window information
* New model categories
* Better descriptions
* Corrections to existing information
* Useful tools and runtimes
* Documentation improvements

## Adding a Model

When adding a model, try to provide the following information:

* Model name
* Organization/company
* Category
* Parameter size
* Context length
* Main capabilities
* License
* API availability
* Local availability
* Recommended hardware
* Official source or repository
* Official documentation when available

Prefer linking to the official model repository, model card, documentation, or API documentation.

## Accuracy

AI models change quickly. Model versions, licenses, APIs, context sizes, pricing, and hardware requirements may change over time.

When updating information:

1. Check the official model source.
2. Verify the current model version.
3. Verify the license.
4. Verify whether an API is available.
5. Avoid presenting estimates as exact specifications.
6. Mention when hardware requirements depend on quantization or runtime configuration.

## Model Licenses

Do not assume that every model described as "open" uses an open-source license.

Use accurate terminology where possible:

* Open Source
* Open Weight
* Open Model
* Commercial API
* Closed Model
* Custom License

Always link to the original license when available.

## Pull Requests

Before submitting a pull request:

* Check that the information is accurate.
* Use official sources where possible.
* Keep formatting consistent with the existing documentation.
* Avoid unnecessary changes.
* Check links for correctness.
* Explain what was added or changed.

## Issues

Please search existing issues before creating a new one.

For model requests, corrections, and other changes, provide enough information for the maintainer to understand the request.

## Keep It Practical

The purpose of this repository is to make model discovery easier.

Prefer useful information such as:

* What the model does
* Where it runs
* How large it is
* Whether it can run locally
* What hardware it needs
* Whether an API exists
* What license it uses
* What it is particularly useful for

Avoid adding models only for the sake of making the list larger.

Thank you for helping improve the repository.
