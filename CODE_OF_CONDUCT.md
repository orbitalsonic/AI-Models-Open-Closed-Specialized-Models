# Code of Conduct

## Our Standards

This project is intended to be a useful and respectful resource for developers, researchers, and AI enthusiasts.

We expect everyone participating in this project to:

* Be respectful and professional.
* Welcome people with different levels of experience.
* Provide constructive feedback.
* Focus on ideas, implementations, models, and technical information rather than individuals.
* Give credit to original model creators and sources.
* Avoid sharing misleading information about model capabilities, licenses, or availability.
* Respect the licenses and terms provided by individual model authors and organizations.

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment or personal attacks.
* Discriminatory or hateful comments.
* Deliberate misinformation.
* Spam or unrelated promotional content.
* Sharing malicious files, links, or code.
* Misrepresenting someone else's work as your own.
* Ignoring the license or usage restrictions of a model or dataset.

## Reporting Problems

If you experience or observe unacceptable behavior, please open an issue with enough information for the maintainers to understand the situation.

For sensitive matters, use the security reporting process described in `SECURITY.md`.

## Scope

This Code of Conduct applies to discussions, issues, pull requests, documentation, and other contributions related to this repository.

## Enforcement

Project maintainers may remove comments, close issues or pull requests, or take other reasonable actions when behavior violates these standards.

The goal is to keep the project useful, welcoming, and technically focused.
